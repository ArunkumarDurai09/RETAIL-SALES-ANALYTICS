# RETAIL-SALES-ANALYTICS
Analyzed retail bicycle and bike sales data using Excel, SQL, Python, and Power BI to identify sales trends, product performance, customer behavior, profitability, and regional insights through an interactive dashboard.
# Project Overview
Retail Sales Analytics is a data analytics project focused on analyzing bicycle and bike retail sales data to uncover meaningful business insights. The project uses Excel, SQL, Python, and Power BI to clean, analyze, visualize, and present sales data through an interactive dashboard.

Power BI
